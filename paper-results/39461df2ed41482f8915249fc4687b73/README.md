# SignalClassifier public paper evidence

Opt-in, typed projections of methods and results. Validation and final test remain separate.
No IQ, weights, private paths, free-text notes, raw metadata, raw events or credentials are included.
Known class codes retain their names; custom classes and identifiers are pseudonyms. Their local mapping is not published.
HPO candidates reference optimization.trials by optimization_trial == trial; full metrics and curves are stored there once. Manual candidates retain their own curves and metrics.
Recording transport does not certify real RF origin. Group aliases preserve within-run split relationships.
Missing data and omitted counts are explicit. This package is not a full private report bundle.
